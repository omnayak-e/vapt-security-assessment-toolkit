# Contributing

Thanks for helping improve **VAPT Security Assessment Toolkit**.

## Development workflow
1. Open an issue describing the bug or proposed improvement.
2. Create a focused branch and keep changes small.
3. Add or update tests for changed behaviour.
4. Run `pytest -q` before opening a pull request.
5. Update documentation and sample output when the CLI changes.

## Security-sensitive contributions
- Test only against systems, files, and traffic you own or are authorised to assess.
- Do not add real credentials, private packet captures, or customer data.
- Report suspected security issues privately to the repository owner rather than publishing exploit details.
