# VAPT Security Assessment Toolkit — Project Guide

A modular, low-impact Python toolkit for authorised TCP exposure checks, HTTP security-header review, structured findings, and reproducible assessment reports.

The repository root README is the main project document. It covers the problem statement, objectives, scope, architecture, methodology, technology stack, installation, usage, interpretation, testing, limitations, and roadmap.
